# 📊 R Data Science & Analytics Projects  

This repository is a collection of my **R-based projects**, showcasing how R can be leveraged for data analysis, visualization, machine learning, SQL integration, and even image processing.  

Most projects are implemented in R notebooks (`.ipynb` with R kernel) and demonstrate complete workflows — from data cleaning and EDA to modeling and insights.  

---

## 📂 Projects  

### 1. 🚗 Car Sales Data Analysis  
- **Notebook:** `Analysis_of_Car_Sales_Data_in_R.ipynb`  
- **Highlights:** Sales trend analysis, EDA, and data visualization in R.  

### 2. 💳 Credit Card Transactions Analysis  
- **Notebook:** `Analyzing_Credit_Card_Transactions_in_R.ipynb`  
- **Highlights:** Transaction behavior insights, fraud detection signals, feature engineering.  

### 3. 🖼️ Image Processing in R  
- **Notebook:** `R_Imager_Package.ipynb`  
- **Highlights:** Image transformations and exploratory image analysis using the R `imager` package.  

### 4. 🗄️ SQL with R  
- **Notebook:** `RSQL.ipynb`  
- **Highlights:** Executing SQL queries directly in R for structured data analysis.  

### 5. 📝 Sentiment Analysis of Customer Reviews  
- **Notebook:** `Sentiment_Analysis_for_Customer_Reviews_in_R.ipynb`  
- **Highlights:** Text preprocessing, sentiment classification, and NLP in R.
